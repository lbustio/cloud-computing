## Filosofía del módulo

Este módulo se enfoca en el despliegue, uso y análisis de una blockchain educativa privada sobre infraestructura cloud real.

El objetivo NO es enseñar desarrollo completo de blockchains, minería avanzada, criptografía profunda ni plataformas blockchain enterprise complejas.

El módulo busca que el estudiante:

- comprenda los fundamentos operativos de blockchain,
- despliegue una blockchain funcional,
- interactúe con bloques y transacciones,
- utilice APIs blockchain,
- analice integridad e inmutabilidad,
- y comprenda aplicaciones y limitaciones reales de tecnologías descentralizadas.

El enfoque será completamente práctico y orientado a experimentación.

## Objetivo general del módulo

Que el estudiante sea capaz de desplegar e interactuar con una blockchain educativa privada sobre infraestructura desplegada en Google Cloud Platform (GCP).

El estudiante deberá comprender:

- bloques,
- hashes,
- transacciones,
- integridad,
- consenso simplificado,
- APIs blockchain,
- y aplicaciones básicas de tecnologías descentralizadas.

## Continuidad con módulos anteriores

Este módulo reutiliza directamente:

- infraestructura cloud desplegada en módulos anteriores,
- máquinas virtuales en GCP,
- conectividad,
- monitoreo,
- y experiencia previa con APIs y servicios web.

La blockchain será desplegada como un servicio funcional sobre infraestructura cloud previamente utilizada durante el curso.

## Justificación del enfoque

El módulo NO utilizará:

- redes blockchain públicas reales,
- criptomonedas reales,
- minería real,
- Hyperledger Fabric,
- Ethereum enterprise,
- smart contracts complejos,
- ni infraestructura blockchain pesada.

Las razones son:

- tiempo limitado,
- complejidad excesiva,
- alto consumo de recursos,
- complejidad operativa,
- y necesidad de mantener un enfoque práctico y educativo.

En su lugar, se utilizará una blockchain educativa ligera basada en:

- Python,
- Flask,
- APIs REST,
- y estructura simplificada de blockchain.

## Stack tecnológico del módulo

El módulo utilizará:

- blockchain educativa basada en GitHub
- JSON
- SSH

## Temas mínimos requeridos

### 1. Introducción a blockchain

Conceptos:

- descentralización,
- bloques,
- hashes,
- integridad,
- inmutabilidad,
- transacciones,
- consenso.

Discusión importante:

Blockchain NO es solamente criptomonedas. Es un mecanismo distribuido para:

- registrar,
- validar,
- proteger,
- y verificar información.

### 2. Estructura de una blockchain

Conceptos mínimos:

- bloque,
- hash,
- bloque génesis,
- cadena,
- transacciones,
- validación,
- proof of work simplificado.

### 3. APIs blockchain

Conceptos mínimos:

- endpoints,
- consultas,
- creación de transacciones,
- minería simplificada,
- validación de cadena.

### 4. Blockchain y ciberseguridad

Aplicaciones posibles:

- integridad de registros,
- auditoría,
- trazabilidad,
- verificación de evidencia,
- almacenamiento verificable,
- registro de eventos.

### 5. Criptomonedas y smart contracts

Introducción conceptual a:

- Bitcoin,
- Ethereum,
- smart contracts,
- tokenización,
- stablecoins,
- activos digitales.

NO se desarrollarán smart contracts complejos.

### 6. Limitaciones y riesgos

Discusión conceptual:

- escalabilidad,
- consumo energético,
- latencia,
- complejidad,
- costos,
- privacidad,
- y limitaciones reales de blockchain.

## Actividad práctica principal

Cada estudiante deberá desplegar y utilizar una blockchain educativa privada sobre infraestructura cloud desplegada en GCP.

- desplegar aplicación,
- configurar entorno,

### Actividad 2. Exploración de bloques y transacciones

Objetivos:

- verificar integridad.

### Actividad 3. Creación de transacciones

Objetivos:

- observar cambios en la cadena.

### Actividad 4. Minería simplificada

Objetivos:

- ejecutar minería educativa,
- comprender proof of work simplificado,

Opciones posibles:

- almacenar evidencia simple,
- verificar integridad de archivos,
- registrar eventos de seguridad.

Objetivos:

- identificar ventajas,
- discutir limitaciones,
- evaluar viabilidad,
- analizar casos de uso reales.
