## Filosofía del módulo

Este módulo se enfoca en la construcción de pipelines modernos para ingestión, almacenamiento, búsqueda y visualización de eventos utilizando infraestructura cloud real.

El objetivo NO es enseñar arquitecturas Big Data complejas ni administración avanzada de clusters distribuidos.

El módulo busca que el estudiante:

- construya pipelines funcionales,
- procese eventos reales,
- analice información,
- visualice datos,
- y comprenda cómo estas tecnologías son utilizadas en observabilidad, monitoreo y ciberseguridad moderna.

El enfoque será completamente práctico.

## Objetivo general del módulo

Que el estudiante sea capaz de construir un pipeline funcional de ingestión y análisis de eventos utilizando Elasticsearch y Kibana desplegados sobre infraestructura cloud en Google Cloud Platform (GCP).

El estudiante deberá comprender:

- ingestión de datos,
- indexación,
- búsqueda distribuida,
- visualización,
- observabilidad,
- monitoreo,
- y análisis de eventos.

## Continuidad con el módulo anterior

Este módulo reutiliza directamente la infraestructura desplegada durante el Módulo 1.

Las máquinas virtuales creadas previamente serán utilizadas para:

- instalar Elasticsearch,
- instalar Kibana,
- exponer servicios,
- procesar datos,
- y construir dashboards.

El curso mantiene así una infraestructura persistente y evolutiva a lo largo de los módulos.

## Justificación tecnológica

El módulo NO utilizará:

- Hadoop,
- Spark clusters,
- Kafka,
- Kubernetes,
- ni arquitecturas enterprise complejas.

Las razones son:

- complejidad excesiva,
- tiempo limitado,
- alto consumo de recursos,
- y poca viabilidad práctica para un curso corto orientado a ciberseguridad aplicada.

En su lugar, se utilizarán herramientas modernas ampliamente utilizadas en:

- observabilidad,
- análisis de eventos,
- monitoreo,
- SIEM,
- telemetría,
- y seguridad cloud.

## Stack tecnológico del módulo

## Actividad práctica principal

Cada estudiante deberá construir un pipeline funcional de ingestión y análisis de eventos utilizando infraestructura cloud desplegada en GCP.

## Infraestructura mínima requerida

Cada estudiante deberá contar con:

- VM Linux en GCP.
- Elasticsearch funcional.
- Kibana funcional.
- Acceso remoto SSH.
- Dataset indexado.
- Dashboard funcional.

## Actividades técnicas sugeridas

### Actividad 1. Instalación de Elasticsearch

Objetivos:

- instalar Elasticsearch,
- configurar servicios,
- verificar funcionamiento,
- exponer APIs básicas,
- validar indexación.

### Actividad 2. Instalación de Kibana

Objetivos:

- instalar Kibana,
- configurar conectividad,
- acceder remotamente,
- crear visualizaciones básicas.

### Actividad 3. Ingestión de datos

Opciones de datasets:

- logs web,
- logs SSH,
- eventos de red,
- datasets JSON,
- registros simulados,
- eventos de seguridad.

Objetivos:

- procesar datos,
- convertir formatos,
- indexar documentos,
- validar ingestión.

### Actividad 4. Consultas y búsqueda

Objetivos:

- realizar búsquedas,
- filtrar eventos,
- utilizar queries básicas,
- explorar información.

### Actividad 5. Construcción de dashboards

Objetivos:

- construir visualizaciones,
- crear dashboards,
- analizar patrones,
- interpretar eventos.

### Actividad 6. Análisis de eventos de seguridad

Ejemplos:

- intentos de login,
- actividad sospechosa,
- tráfico anómalo,
- eventos repetitivos,
- análisis temporal.
