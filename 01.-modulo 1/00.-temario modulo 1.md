## Filosofía del módulo

Este módulo NO se enfoca en memorizar definiciones o modelos conceptuales de computación en la nube. El objetivo principal es que el estudiante comprenda el paradigma cloud mediante despliegues reales, administración básica de infraestructura y resolución de problemas técnicos prácticos.

El aprendizaje estará centrado en:

- exploración técnica,
- despliegue de infraestructura,
- documentación,
- troubleshooting,
- análisis de riesgos,
- y trabajo autónomo.

El profesor funcionará principalmente como:

- coordinador técnico,
- guía,
- moderador,
- y apoyo para resolución de bloqueos.

## Objetivo general del módulo

Que el estudiante sea capaz de desplegar y administrar infraestructura básica en una plataforma cloud real, comprendiendo:

- modelos de servicio,
- modelos de despliegue,
- arquitectura cloud,
- aspectos de conectividad,
- costos,
- y riesgos de seguridad fundamentales.

## Plataforma seleccionada

Se utilizará exclusivamente Google Cloud Platform (GCP) durante todo el curso.

## Justificación de la selección de GCP

La decisión de utilizar únicamente GCP se basa en los siguientes factores:

### Ventajas principales

- Interfaz considerablemente más limpia y menos caótica que AWS.
- Curva de aprendizaje inicial más razonable para estudiantes.
- Integración muy buena con IA, notebooks y herramientas modernas.
- Créditos gratuitos relativamente accesibles.
- Excelente integración con Docker, Kubernetes y APIs modernas.
- Buena documentación.
- Menor fricción inicial que Azure y AWS.

### Razones para NO usar AWS

AWS domina la industria, pero para un curso corto presenta varios problemas:

- Consola extremadamente compleja.
- Curva de aprendizaje alta.
- Exceso de servicios.
- Troubleshooting más difícil para principiantes.
- Mayor riesgo de errores de facturación.
- IAM innecesariamente complejo para un curso introductorio.

### Razones para NO usar Azure

Azure tiene buena integración empresarial, pero:

- La experiencia de usuario es inconsistente.
- La documentación frecuentemente es confusa.
- La interfaz cambia demasiado.
- Tiene demasiada orientación enterprise/corporativa.
- El ecosistema puede resultar excesivamente pesado para un curso introductorio práctico.

## Temas mínimos requeridos

### 1. ¿Qué es realmente cloud computing?

- Virtualización.
- Elasticidad.
- Escalabilidad.
- Pago por consumo.
- Infraestructura distribuida.
- Disponibilidad geográfica.

Discusión importante:

Cloud computing NO es simplemente “usar servidores remotos”. El estudiante debe comprender:

- abstracción de infraestructura,
- automatización,
- elasticidad,
- y administración distribuida.

### 2. Modelos de servicio

- IaaS
- PaaS
- SaaS

La comprensión debe ser práctica y no memorística.

Ejemplos reales:

- IaaS:
  - Google Compute Engine
  - Amazon EC2

- PaaS:
  - Google App Engine
  - Heroku

- SaaS:
  - Gmail
  - Office 365
  - Google Docs

### 3. Modelos de despliegue

- Nube pública.
- Nube privada.
- Nube híbrida.
- Multi-cloud.

Discusión práctica:

- ventajas,
- costos,
- riesgos,
- dependencia de proveedor,
- compliance,
- y soberanía de datos.

### 4. Arquitectura básica cloud

- regiones,
- zonas,
- VPC,
- subredes,
- IPs públicas,
- firewalls,
- almacenamiento,
- snapshots,
- balanceadores básicos.

### 5. Costos y ROI

Introducción mínima a:

- billing,
- cuotas,
- free tiers,
- consumo,
- y costos ocultos.

Tema obligatorio:

Muchos incidentes cloud NO son técnicos sino económicos.

### 6. Introducción mínima a normativas

Introducción conceptual a:

- GDPR,
- ISO 27017,
- ISO 27018,
- privacidad,
- protección de datos,
- y compliance.

NO se profundizará jurídicamente.

## Actividad práctica principal

Cada estudiante deberá desplegar infraestructura funcional real en GCP.

## Infraestructura mínima requerida

Cada estudiante deberá desplegar:

- 1 máquina virtual Linux.
- 1 bucket de almacenamiento.
- Configuración básica de firewall.
- Acceso SSH funcional.
- Servicio web mínimo funcional.
- Evidencia de conectividad pública.

## Actividades técnicas sugeridas

### Actividad 1. Creación de cuenta cloud

Objetivos:

- Crear cuenta GCP.
- Activar créditos gratuitos.
- Comprender billing.
- Configurar autenticación básica.

### Actividad 2. Despliegue de máquina virtual

Objetivos:

- Crear VM Linux.
- Configurar región y zona.
- Asignar recursos.
- Configurar acceso SSH.
- Verificar conectividad.

### Actividad 3. Configuración de firewall

Objetivos:

- Abrir puertos específicos.
- Comprender tráfico entrante/saliente.
- Analizar superficie de exposición.

### Actividad 4. Despliegue de servicio web simple

Opciones posibles:

- nginx,
- apache,
- flask,
- fastapi,
- nodejs,
- docker container.

Objetivo:

Publicar un servicio accesible desde Internet.

### Actividad 5. Almacenamiento cloud

Objetivos:

- Crear bucket.
- Subir archivos.
- Configurar permisos básicos.
- Comprender almacenamiento distribuido.

## Troubleshooting obligatorio

Parte importante del aprendizaje será resolver problemas reales relacionados con:

- permisos,
- firewalls,
- puertos,
- llaves SSH,
- errores de autenticación,
- rutas,
- DNS,
- facturación,
- cuotas,
- y despliegues fallidos.

El troubleshooting NO es un accidente del curso. Es parte central del aprendizaje.
